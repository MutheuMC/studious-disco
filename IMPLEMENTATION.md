# Implementation status

The application uses separate frontend/ and backend/ folders, with the backend’s database types generated by Prisma.

## Delivered

- Account creation, password sessions, optional Google login, and personal-owner restriction.
- Dashboard, application list and board, filters, details, notes, deadlines, history, and status changes.
- Persistent profile and job source memory, including explicit remember commands in assistant chat.
- Safe RSS/Atom/structured-listing discovery, duplicate detection, manual job descriptions, and optional broad search.
- Private document upload, editable immutable versions, PDF/DOCX export, and optional AI drafts.
- Optional Gmail read/send integration with encrypted tokens, reviewable matches, and uncertain-send protection.
- Optional Telegram pairing, reminders, and notifications.
- Scheduled jobs, database leases, retries, source status, worker history, and CI configuration.

## Requires your configuration

Google OAuth/Gmail credentials, a Telegram bot, an AI provider/model, and a search provider key are not included. The Settings screen reports readiness. No real employer emails were sent during verification.

## Still outside this release

Universal website support, automatic extraction of uploaded CV facts, password recovery, quiet-hour/digest controls, automated portal completion, and unattended automatic email applications. The assistant prepares drafts after a user action and sends only with explicit review.

See README.md for installation, development, tests, and deployment requirements.

- Backend TypeScript compilation and frontend production build passed.
- 44 automated tests passed against a separate PostgreSQL test database, including Google OAuth coverage.

## Google account access

Explicit Google sign-in and sign-up screens are implemented. OAuth uses state, PKCE, nonce, verified email, and stable Google subject IDs. Tests cover signup, returning login, owner restrictions, safe identity linking, cancellation, expired/tampered flows, and separate Gmail consent. Google buttons report setup requirements until real credentials are configured. See docs/google-auth.md. The final production build and type checks passed; all 44 tests passed. Live Google authentication remains unverified because OAuth client credentials are not configured.
